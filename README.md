# DynamicNotch

A macOS-style Dynamic Island for Windows laptops, built with WPF (.NET 8).

## Features

- **Dynamic Island UI**: A sleek, rounded notch at the top of your screen that expands on hover
- **Media Controls**: Automatically detects and displays currently playing media from Spotify, YouTube, Netflix, Apple Music, VLC, etc.
- **Real-time Calendar**: Shows the current week with today highlighted
- **Mirror/Webcam**: Toggle your webcam feed as a quick mirror
- **Smooth Animations**: Apple-style cubic-ease transitions
- **Settings**: Configurable startup, toggle sections on/off
- **Always on Top**: Stays above all windows without stealing focus

## Requirements

- Windows 10 (19041+) or Windows 11
- .NET 8.0 SDK
- Webcam (optional, for Mirror feature)
